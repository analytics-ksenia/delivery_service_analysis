# delivery_service_analysis
Проект: Анализ и проектирование сервиса доставки заказов

Описание проекта:
На основе вводной бизнес-задачи (в документе DELI_task) выполнить предварительный системный и бизнес-анализ сервиса доставки:
- собрать и структурировать требования стейкхолдеров
- смоделировать сквозной процесс обработки и выполнения заказа от поступления до выплаты
- описать движение потоков данных внутри системы и логику смены статусов заказа
- разработать логическую структуру базы данных и составить словарь атрибутов для хранения сущностей

Содержание репозитория:
- DELI_task - файл с исходным заданием и требованиями к системе
- DELI_requirements - таблица требований: роли в системе, проблемы текущей работы(as-is),требования к новому функционалу(to-be) и потоки данных
- DELI_context_diagram - контекстная диаграмма: показывает кто и какими данными обменивается с системой
- DELI_bpmn - процессная диаграмма BPMN: пошагово показывает действия каждого участника от создания заказа до доставки
- DELI_dfd - диаграмма потоков данных: показывает процессы обработки информации в системе и то, в какие хранилища она записывается
- DELI_state - диаграмма состояний: отражает жизненный цикл заказа и смену статусов
- DELI_model - ER-модель: схема таблиц базы даннных и связей между ними
- DELI_dictionary - словарь данных: перечень атрибутов для каждой сущности
